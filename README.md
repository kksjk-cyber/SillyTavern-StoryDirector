# Story Director 2.0.0 — 剧情调度器测试版

本版继承 V1.2 的中文面板、BM25、向量检索、预算和 Gemini 候选筛选，增加 SAG-inspired 实体关联、跨轮事件状态与计划、成功生成后的快照提交。只面向已审核的普通小说、冒险、世界观资料，不支持直接导入原始成人世界书。不会修改原始世界书或聊天正文。

## 安装（Windows）
1. 停止 SillyTavern。先停用 V1.2，备份原有扩展与资料，不要同时运行两个版本。
2. 解压 ZIP，将整个 `StoryDirector-2.0.0` 文件夹（内含 manifest.json）放入 `SillyTavern/data/default-user/extensions/`；多用户使用对应用户目录。部分旧版/分支使用 `public/scripts/extensions/third-party/`，以实际版本为准。
3. 重启酒馆，刷新浏览器，打开扩展设置，查找 Story Director 2.0。点击“载入示例”，勾选启用普通剧情资料调度、SAG 式实体关联检索。默认不发送额外 AI 请求。
4. 在普通剧情聊天中发送“我想调查旧航图”，查看日志中的候选、关联路径、注入与 Token 数。示例包含航图→北辰印记→制图师协会的关联链。
5. 如需 AI 调度，先确保当前酒馆 Gemini/302.AI 连接正常，再勾选“允许额外 AI 请求”。调度器复用宿主 generateRaw，不另存 API Key；每轮可能产生额外一次付费请求，近期聊天和候选摘要会发给模型供应商。不会自动重试。
6. 向量模式可选：点击“重建向量索引”，使用宿主 Transformers 后端。首次可能需要模型下载；失败时保留关键词检索。该模式依赖酒馆的实际 API 版本和服务器环境。
7. V2 使用独立 IndexedDB 和向量集合，不自动迁移 V1.2 快照。重新导入已经审核过的 V1.2 资料 JSON 即可，旧资料不覆盖。

## 推荐设置
每轮4条，2500 Token（同时不超过上下文预算25%），扫描10条消息，冷却5个用户轮，候选有效期6轮，SAG式关联开启，AI/向量按需开启。世界过滤为空时不预先限定世界；最好明确设置世界名。

## 数据格式
`example.json` 使用 `story-director-lore-v1`，与 V1.2 的已审核普通剧情资料兼容。每条包含 id、title、summary、content、world、tags、reviewed:true；kind 为 fact 或 event。可选 entities（明确的共享实体名称）、requires（事实 ID）、conflicts（互斥 ID）、group、enabled。旧条目没有 entities 时使用 tags。人工审核是必要条件，关键词过滤并不是完整内容审核器。

## SAG-inspired 检索
1. BM25 和可选向量检索得到种子条目。
2. 内存 Map 保存实体→条目及条目→实体关联。
3. 查询时从种子扩展最多两跳，过滤世界冲突、高频实体和过多候选；关联路径保留在日志中。
4. 合并既有事件和未完成目标、候选去重，交给 AI（如开启）筛选，最后经过预算、依赖和冲突限制才注入原始资料。
这是 SAG 思路的轻量实现，非官方 SAG 引擎：没有 SQL、自动事件/实体抽取、实体消歧、完整原论文检索评分或官方性能复现。实体由用户审核并提供，标签不一定等于实体。SAG 关联本身不证明因果。

## 剧情状态与生命周期
- offered：资料已作为可能线索提供，不等于已发生。
- active：AI 从已有近期聊天引用原文证据，且满足上一状态要求。
- resolved / abandoned：仅 active 可以进入终态，终态不再自动选择注入。
- expired：未推进的 offered 达到有效期后标记过期，可在新的合适情境重新提议。
- goals：引用已知候选事件的短期计划，1–8用户轮，有效期结束自动清除。
- 模型返回的证据必须是已有对话子串，但这不保证模型正确理解含义，需人工核对。
- 生成前只暂存状态；生成结束时校验历史前缀和新助手消息后才提交。最多保留200个完整历史哈希快照。编辑后回到最近匹配的前缀；切换聊天独立保存。继续生成（continue）未启用调度；某些 swipe、群聊、第三方分支事件顺序可能导致保守跳过提交。
- 状态计划本身不会强制用户选择。当前实现是有限期事件规划，不是无限长的小说大纲生成器；状态识别可能滞后一轮。

## 排错、隐私与卸载
- 无候选：检查世界、资料及输入。可开启本地向量。
- 额外请求错误：关闭AI，仍可检索背景事实；检查模型余额和宿主日志。
- 注入未出现：检查真实生成是否触发 interceptor，用 Prompt Inspector 核验。
- 数据保存在当前浏览器站点 IndexedDB（story-director-v20），向量集合为 story-director-reviewed-lore-v20。勿存敏感信息；卸载不会自动删除数据。通过浏览器开发者工具或宿主索引管理单独清理本插件数据。
- F12 检查控制台。若使用 CicaTavern 等分支，需测试是否兼容宿主的事件、注入及向量接口。

## 测试与范围
Node.js 18+，在插件目录运行 `npm test`，无需安装依赖。19项单元测试通过（见 TEST-RESULTS.txt）。已做 JS 语法检查；未连接真实酒馆、浏览器或302.AI进行端到端验证，不保证所有版本兼容。
