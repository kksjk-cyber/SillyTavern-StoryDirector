# Random Variable Engine 1.0.0（测试版）

SillyTavern 第三方扩展。基于用户提供的 v1_02 预设的普通叙事随机演算规则重新实现；不依赖 Tavern Helper 或 SPreset，也不覆盖 Story Director。

## 安装（安卓酒馆 APK）
APK 若只提供 Git URL：在 GitHub 新建独立公开仓库（例如 SillyTavern-RandomVariableEngine），初始化 README，然后上传本包解压目录内文件，manifest.json 必须在仓库根目录。将实际仓库的 https://github.com/用户名/仓库名.git 粘贴到安装扩展的 Git URL。不要上传原预设、世界书、聊天记录或密钥。当前包尚未发布至 GitHub。标准 ST 可将目录放入 data/<user-handle>/extensions 并重启。

## 第一次使用
1. 切换到不含原随机变数规则的普通预设；关闭原预设的悬浮窗脚本和同类正则，避免双重判定。不要删除原文件。
2. 在扩展面板找到「随机变数引擎 1.0」。总开关默认开启；AI 自动识别默认关闭（避免未授权的额外 API 请求）。点击本地自检，应出现身份、人格、未知三项计算结果。
3. 需要自动识别时勾选 AI 自动识别，复用 ST 当前模型连接，额外请求可能收费。无需填写密钥。保持自动产生种子开启，或长按骰子/点击生成种子把10位数字插入输入框。用户手动输入的有效种子优先。
4. 测试普通剧情：上一轮已有一个密封航图盒，本轮用户说“我试着打开之前发现的航图盒”。检查诊断日志、判定日志、实际注入文本。若不想付费，可点击填入测试队列，在对应的普通场景中测试。生成完成后队列清空。
5. 有选项/场景/状态输出时在扩展面板查看，点击选项仅追加至输入框，不会自动发送。

## 移植范围与限制
- 八类变数：身份/人格/初见预演；战斗/未知/情绪/变故/策略及时类。身份前2位、人格前4位、初见中间2位，战斗/未知按阵营首末位，策略仅友敌NPC，情绪/变故首位。两个池独立。数字0–1、2–3、4–5、6–7、8–9五档。原文身份5/6与初见4区间重叠，采用普通或小有名气/有一定分量及统一五档；中位奇数向左取整；补全解释为从原始种子首部补到10位，再翻转。人格池保留100个位置，部分标签改为普通人物性格。不是逐字复制原预设。
- 每次提前识别候选事件，再由程序计算。及时判定在生成前计算，模型在相应情节发生时应用，并可报告编号；不是真正的逐句暂停/工具调用。分类标记由模型提供，无法独立证明剧情前提正确。未发生的事件可跳过。没有全局角色身份去重数据库或跨轮角色状态自动写回。
- 悬浮按钮固定位置；点按打开设置，长按生成种子。面板展示状态、选择与判定记录，不复现原有 HTML iframe/正文内折叠样式；原正则功能不全部迁移。隐藏点数提示只影响模型应用编号提示，不隐藏诊断日志。
- 保留无、严肃、招笑、奇诡基调及普通叙事辅助；不移植色情基调、强制思维链、破甲/输出锁或强制联网同人搜索。没有修改模型安全设置。无原预设的宏变量副作用和外部日志上传。
- 不保存 API 密钥、不调用额外外部服务，AI 分类复用酒馆当前 API，发送最多最近12条消息各1800字符。配置由 ST 扩展设置保存；本轮日志为会话内存，不承诺跨刷新历史保存。
- 官方 ST Prompt Interceptor 机制：https://docs.sillytavern.app/for-contributors/writing-extensions/ 。未在 OPPO Pad APK、CicaTavern 或真实 Gemini 接口端到端测试。若日志无“收到生成拦截器”，APK 可能不支持该接口；若提示缺少 generateRaw 或动态注入接口，需针对具体版本适配。注入预览是传给宿主的文本，不是最终 API 报文。

## 测试
`npm test` 或 `node --test tests.mjs`（无需 npm install）。查看 TEST-RESULTS.txt。测试覆盖纯函数，不覆盖真实宿主、浏览器交互、API 网络请求或生成效果。
